# data/

This folder holds metadata generated by the project — **not** the dataset itself.

Generated files:
- `dataset_summary.json` — class counts, image totals, imbalance stats
- `class_mapping.json` — `{ClassId: ClassName}` from labels.csv
- `data_split.json` — file paths and integer labels for train / val / test

The actual dataset stays in its original location:
- `../traffic_Data/DATA/` — training images (58 class folders)
- `../traffic_Data/TEST/` — test images
- `../labels.csv` — class descriptions

Do **not** copy the dataset into this folder.
